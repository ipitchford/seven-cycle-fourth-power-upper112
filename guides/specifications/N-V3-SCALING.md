# Full-root adapter, version3

This version preserves every native catalogue, relation/index, domain, allocation-CSP, parser, diagnostic and cube arithmetic byte from reviewed version2. It adds a Python adapter for an explicit disjoint root inventory and extends only the fixed root/mode/direct-key gates in raw geometry.

Each root packet retains its own pair IDs, binary records, vector IDs and expected exact cost digest. The coverage-only combined input renumbers pair IDs and adds a disjoint per-root vector offset to each certificate ID. The 66 assignment bits and ordered bands are conserved exactly. Native coverage uses the transformed certificate ID only for a range check; the final raw geometry reads the original root packet and vector. The driver checks exact per-root model counts and every pair/model/direct consumption, then rechecks all original packet hashes. Counts and registry identity are cross-checks, not substitutes for regeneration.

Full mode requires exactly roots0..1015, with all-partner modes0..16,500,925,970,1015 and ordered modes for the other995. It requires exactly4,356,002 ordinary models and the three named direct keys533/10134799,538/9040899,569/9370834. Scope is the target113 nonadjacent-band N component, not the unrestricted bound. The extra pilot fixes roots164,533,1015 to test both modes and a nontrivial stabilizer.

One native process constructs a fresh index once and visits every root. The per-root120-second Solver/candidate deadline and all joined/state/model failure behavior are unchanged. Native global limit is7800seconds full,480seconds pilot; its owning Python stage has an additional60-second wall margin. The whole driver has a10800-second budget. Census600s, mixed77 180s, compiler120s, diagnostic90s and geometry180s/root limits remain. The stage executor pins binary/source/input hashes, terminates only its owned process group on timeout, writes terminal evidence, and rejects peak child RSS above1.3GiB. The driver requires at least20GiB free at launch. Expected full elapsed time is50–75minutes; the3-hour ceiling is not a proof premise. Timeout, cap, missing/excess model, or any unconsumed entry causes failure.

`controls_scaling.py` independently roundtrips every combined record and certificate offset, exercises the unchanged native parser on the combined input, corrupts root inventory/mode/count metadata, and optionally corrupts the freshly generated multi-root coverage ledger. These source/adapter controls complement version2's29 corruption and4 actual-Solver cap controls. The three-root fresh pilot must pass before full execution.

The compact exporter is separate. An exported packet and an accepted historical registry receipt do not establish fresh completeness. Full success additionally requires the actual fresh census/no34 and mixed77 dependency replays, labelled catalogue/domain/candidate enumeration, all ordinary model comparisons, three direct complete cube covers and raw integer geometric checks performed by this version.
