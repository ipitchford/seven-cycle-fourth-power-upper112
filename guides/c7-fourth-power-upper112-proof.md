## Exact residual bounds and conclusion

Adjacent product windows restricted in one, two, three or four coordinates
have capacities33,10,3 or1 by injective projection. Nonnegative integer-weighted
sums of these inequalities, with exact singleton repairs on uncovered residual
vertices, give the rational bounds. The checkers reconstruct the original2,401
vertices and use integer arithmetic. Numerical optimizer status supplies no
proof premise.

N excludes the nonadjacent alternative, and A excludes the remaining adjacent
alternative. Hence no113-word independent set exists. Any larger independent
set would have a113-word subset, giving the upper bound112. The literal108-word
witness gives the lower bound.

each have at most112 points, and count each original point twice, so
\(2|S|\leq7\cdot112=784\). This is an upper bound, not an exact-value claim.
