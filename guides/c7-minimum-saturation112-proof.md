# Meaning of the independently checked stage recurrence

The theorem premise is an independent set S of 112 vertices of C7 strong power
4, with every coordinate layer of size 16, no size-33 adjacent band, and minimum
saturation in all six unordered coordinate pairs. Balancedness is explicit;
deriving it from a broader no33 premise additionally uses the known upper33
bound in dimension three and is outside this dependency census.

For axes a,b define B_ab(i,j) as the number of points in the corresponding
adjacent two-coordinate window. Projection into the remaining square is
injective and independent, so B_ab(i,j)<=10. Every row and column sums to64.
If a row has z tens then z-1 is the sum of 9-B over entries at most8. Thus there
are at least seven tens. The minimum premise says exactly seven for each axis
pair, forcing B_ab=9J+P_ab, with P_ab a permutation matrix. All28 adjacent
three-dimensional bands of S therefore have32 points and exactly one saturated
square band in each of their three directions.

The fresh dependency enumerates precisely this restricted family, with11,175
isometry classes. Let F0 be all their original atlas indices. For any family F,
define D(F) by taking every representative in F, all three choices of outer
coordinate, seven windows, both orientations, and the entire392-element plane
isometry action. Canonicalizing the union and then applying all its stabilizers
implements exactly these maps. Every allowed split has a full physical witness
from F; conversely every possible witness from F contributes its split.

For a literal representative C, its32 words have one common Boolean allocation
to outer layers0 and1, with16 words each. For each of its21 transverse windows,
the corresponding tuple must lie in D(F). If C is the image of an actual band
of S and all bands of S have classes in F, then each transverse band supplies
the required witness. The same global32 variables must be used in all queries.
The isometry used to normalize C extends over its three coordinates while
fixing the outer coordinate, so the shared-variable argument is invariant.

Define F(k+1) by removing only classes for which a complete checked tree refutes
this necessary allocation CSP built from D(Fk). SAT and UNKNOWN remain. By
induction every actual band class of S belongs to every Fk: this holds initially
by the census, and an actual allocation cannot be refuted by a valid tree.
Hence an empty checked survivor family excludes S under the stated premises.
A nonempty family proves only a reduction, even if every retained assignment
has21 individually valid witnesses. Those witnesses need not coexist in a
single four-dimensional set.

The domains must be rebuilt from the current providers, not filtered by the
one witness retained for each original split. A split can have another witness
in the surviving family even when its stored original witness was removed.
The implementation initializes the initial canonical-key universe to empty
at every later round, then enumerates every current provider and all maps.

Tree soundness is a separate elementary induction. At each branch the explicit
assignment list is extended by0 and1 on a fresh variable. A leaf closes only
if exact16 is impossible or every tuple of the named reconstructed predicate
disagrees with an assigned variable. A complete binary tree thus covers every
possible total allocation and proves the necessary CSP UNSAT. No search
heuristic, machine timing, node count, learned lemma or native status is used
as a mathematical premise.

This staged argument strengthens the original one-round test without changing
the underlying conditional branch. It does not establish arbitrary112
exclusion, an upper111 bound, a complete size32 census, or the original109
optimum. Those quantifiers require separate evidence.
